PyVOBeSS is a set of functions to request and parse BeSS data for several purpose :
- Automatic detection of changes compared to previous month or lastest record of a Be H-alpha spectrum with automatic classification of the change Emission Event, Moderate Event, Decreasing Event (EE, ME, DE)
- Request and upload of BeSS spectra for a given object between dates
- Given a month, get all the month BeSS stars observed, detect and classify changes and generate word and pdf BeSS monthly report automatically

There is no user interface, code for function selection, object, dates has to be entered in the code directly for now

Also included lib_vspec.py which includes basic profiles processings adapted from my Visual Spec software, a Visual Basic 30 years old app for spectroscopy amateurs which is still alive...
